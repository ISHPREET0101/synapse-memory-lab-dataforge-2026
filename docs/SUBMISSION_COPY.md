## Title

Synapse Memory Lab

## Tagline

See causal linear attention become a fixed-shape synaptic memory—and then break it on purpose.

## Short description

Synapse Memory Lab is an interactive visual essay about the memory mechanism behind BDH-GPU. A learner watches Hebbian-like outer-product writes alter a fixed-shape state, verifies an exact recurrent-versus-explicit-history identity for causal linear attention, contrasts that result with non-equivalent softmax attention, and stress-tests a separate associative memory until interference appears. Every lab is deterministic and computed live in the browser. Author-reported research results, synthetic measurements, and limitations are labeled separately.

## What makes it different

Most explainers stop at animation. This one exposes the state, proves one equality numerically, invites falsification with real controls, and makes the failure mode part of the lesson. It is deliberately honest about what it does not establish: the project is not an official Pathway model, it does not run a trained BDH/BDH-CQ checkpoint, and its associative-memory curve is not a BDH capacity benchmark.

## Built with

TypeScript, Vite, Canvas 2D, Vitest, and a dependency-free static runtime.
