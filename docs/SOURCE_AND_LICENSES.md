## Data and model inventory

| Category | Present? | Details |
|---|---:|---|
| External datasets | No | No downloaded or bundled dataset. |
| Personal or user data | No | The app has no input persistence, account system, analytics, cookies, or telemetry. |
| Model weights/checkpoints | No | No BDH, BDH-CQ, Transformer, or other learned checkpoint is bundled or fetched. |
| Live BDH inference | No | No official checkpoint has been run by this project. |
| Synthetic token data | Yes | Hard-coded integer token sequences with display labels in `src/labs/lab1.ts` and `src/labs/lab2.ts`. |
| Synthetic association data | Yes | Deterministic unit vectors generated by `mulberry32` in `src/engine/retrieval.ts`. |
| Random toy parameters | Yes | Deterministic seeded Gaussian `E`, `Dx`, and `Dy` matrices generated in `src/engine/bdh.ts`. |
| Precomputed result files | No | There is no `public/data` result bundle in the current implementation. The static comparison table is prose, not a loaded dataset. |

Synthetic outputs are generated locally in the browser. They should not be described as samples from an official model or real corpus.

## Fonts, graphics, and external requests

- Fonts use the browser/system sans-serif stack; no font files or remote font service are included.
- All charts, neuron maps, and synapse heatmaps are drawn by local Canvas 2D code.
- No stock images, icons, audio, video, or third-party design files are bundled.
- The production artifact needs no post-load API request. Source links are ordinary outbound links clicked by the learner.

## Software dependencies

There are no runtime package dependencies. The build/test toolchain is development-only:

| Direct package | Declared range | Purpose | License recorded by installed package |
|---|---:|---|---|
| TypeScript | `^5.5.0` | Static type checking | Apache-2.0 |
| Vite | `^5.4.0` | Development server and static bundling | MIT |
| Vitest | `^2.0.0` | Unit tests | MIT |

Exact resolved versions and transitive packages are pinned in `package-lock.json`. Their license notices remain in the respective package distributions under `node_modules` after `npm ci`; `node_modules` is not project-authored material and should not be committed as source. Before release, regenerate the dependency inventory from a clean lockfile and review any license-policy requirements.
